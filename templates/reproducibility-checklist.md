# Reproducibility Checklist

> Complete before circulating the paper or freezing the final empirical dataset.

## Raw Data

- [ ] Original source documented
- [ ] Acquisition date recorded
- [ ] Source identifiers preserved
- [ ] Raw files immutable
- [ ] Licensing/access restrictions documented
- [ ] Raw-document hashes stored where feasible

## Corpus / Sample Construction

- [ ] Inclusion criteria coded
- [ ] Exclusion criteria coded
- [ ] Sample-flow counts reproducible
- [ ] Unit of analysis stable and documented
- [ ] Duplicates / near-duplicates checked
- [ ] Parsing failures logged

## Annotation

- [ ] Construct codebook frozen
- [ ] Coder training documented
- [ ] Pilot sample preserved
- [ ] Gold sample preserved
- [ ] Human agreement reported
- [ ] Adjudication rules preserved
- [ ] Final test labels isolated from model/prompt development

## Modeling

- [ ] Baseline retained
- [ ] Preferred model recorded
- [ ] Package versions recorded
- [ ] Model name/revision recorded
- [ ] Hyperparameters recorded
- [ ] Random seeds recorded
- [ ] Train/validation/test IDs stored
- [ ] Firm/time leakage checked
- [ ] Near-duplicate leakage checked

## LLM Measurement

If applicable:

- [ ] Provider/model recorded
- [ ] Model/version or snapshot recorded where exposed
- [ ] Inference dates recorded
- [ ] System prompt preserved
- [ ] User prompt template preserved
- [ ] Few-shot examples versioned
- [ ] Structured output schema preserved
- [ ] Failed calls/retries logged
- [ ] Raw responses archived where permitted
- [ ] Prompt/model robustness run
- [ ] Self-reported confidence not treated as calibrated probability without validation

## Embeddings / Topic Models

If applicable:

- [ ] Embedding model recorded
- [ ] Embedding rows linked to stable text IDs
- [ ] Text hashes stored
- [ ] UMAP/HDBSCAN parameters recorded
- [ ] Topic-model seeds/settings recorded
- [ ] Stability tests archived
- [ ] Human topic interpretation archived
- [ ] Topic taxonomy version frozen

## Causal ML

If applicable:

- [ ] Estimand explicitly stated
- [ ] Identification assumptions documented
- [ ] Treatment/outcome timing checked
- [ ] Post-treatment controls excluded or justified
- [ ] Overlap assessed
- [ ] Cross-fitting splits preserved
- [ ] Cluster/group structure respected
- [ ] Alternative nuisance learners checked
- [ ] Conventional causal benchmark reported

## Variable Construction

- [ ] Passage/document outputs preserved
- [ ] Aggregation code preserved
- [ ] Final variable definitions frozen
- [ ] Alternative aggregations documented
- [ ] Missing/failed model outputs handled transparently

## Econometrics

- [ ] Analysis dataset generated by code
- [ ] Fixed effects documented
- [ ] Standard-error clustering documented
- [ ] Main specification reproducible
- [ ] Table/figure scripts regenerate outputs
- [ ] Robustness specifications versioned

## Environment

- [ ] Python version recorded
- [ ] Lockfile / environment file created
- [ ] OS/hardware-sensitive steps documented
- [ ] External API dependencies documented
- [ ] Secrets excluded from repository

## Repository

- [ ] README explains reproduction order
- [ ] `.gitignore` excludes secrets/raw restricted data
- [ ] Method decision log complete
- [ ] Final code commit/tag recorded
- [ ] Generated intermediate files clearly separated from source code

## Final Audit

Another researcher should be able to answer:

1. Where did each raw observation come from?
2. Which exact text produced each model output?
3. Which model/prompt/version produced each derived variable?
4. Which observations were used for training, validation, and testing?
5. How was the final firm-level variable aggregated?
6. Which code recreates every main table and figure?
